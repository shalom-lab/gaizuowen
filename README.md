# 作文批改助手

拍照上传学生作文 → 自动识别手写文字 → 给出**可以直接抄到作文本上的批注**和一段总评。

**线上地址：https://gzw.rlearner.com** —— 手机打开就能用。

手机、电脑都能用。**建议加到手机主屏幕**，用起来像 App 一样。

> iPhone：用 Safari 打开 → 点底部「分享」→「添加到主屏幕」  
> 安卓：用浏览器打开 → 菜单 →「添加到主屏幕」

应用内第一次打开会自动出现「**使用介绍**」，之后可点右上角**问号**随时再看。仓库里这份说明与应用内介绍讲的是同一套步骤。

开发者请看 **[开发说明.md](开发说明.md)**。

---

## 第一步：打开网页

**https://gzw.rlearner.com**

第一次打开会自动出现「**使用介绍**」，看完点「**知道了**」即可。
之后可点右上角的**问号**随时再看。

---

## 第二步：配置 API Key（只需一次）

**DeepSeek** 是一家国产 AI 公司；真正识别和批改作文的，是它的模型。
**API Key** 相当于调用它的钥匙——本页本身不会批改，只是替你把作文发给它。
注册后通常有**免费额度**；本工具也做了**调用优化**，批一篇大约**几分钱**，费用不会太高。

1. 首次打开会看到「**先填入 DeepSeek API Key**」的提示，点「**去设置**」
   （或点右上角的**齿轮图标**）
2. 把 Key **粘贴**到输入框
3. 点最下方的「**保存**」→ 会先验证连接，出现「**连接成功，已保存**」就对了

配置一次就够了，以后打开直接能用。密钥不对时不会保存，会提示原因。
密钥只存在**你自己的手机里**，不会上传到任何服务器。

> 不知道去哪拿 Key？看本文「关于 DeepSeek API Key」。

---

## 第三步：上传作文

回到主界面，两种方式：

- **拍照上传** —— 对准作文，拍一页收录一页，适合现场批
- **从相册选择** —— 可以一次选中多张

一篇作文写了好几页也没关系，**继续拍**就往下加。

**翻页**：主图（或放大后）**左右滑动**即可；缩略图下的左右箭头也是翻页。
**调整顺序**：缩略图**长按约半秒**再拖动，可换页码顺序。
批改会严格按第 1 页 → 第 N 页 的顺序读，**顺序错了会影响结果，提交前先看一眼**。

（年级、学生姓名是选填的，不填也能批。）

---

## 第四步：提交批改

点「**提交批改（N 页）**」。

**第一次要等一下**，大约 **30～90 秒**（页数越多越久）。

**但不用守着它。** 提交之后可以**立刻接着拍下一篇**，批改在后台自己跑。
批好会在顶部弹一条提示，点开就能看。

> 一次可以排 20 篇，同时批 2 篇。
> 上课间隙拍几篇进去，等你坐下来的时候就已经批好了。

---

## 第五步：照着抄批注

批好后点提示，或点右上角的**批改记录图标**打开。

页面上是这样：

- **原文一个字都没改**，出问题的地方后面用 `〔→ 改正〕` 标出正确写法
- **每段下方**列出这段的所有批注，编号和正文里的编号一一对应
- **直线** = 要改的地方；**波浪线** = 写得好的句子
- 一段一段往下照着抄就行，不用来回找

**抄的时候手机不会熄屏**（打开批改结果时会自动保持常亮），不用担心抄到一半黑屏。

这一篇抄完，点「**批改下一篇**」继续。

---

## 第六步：导出（可选）

想把批注打成纸给家长，或者存一份档：

1. 打开**批改记录**
2. 点「**选择**」→ 勾选要导出的作文（也可以点「全选当前 N 篇」）
3. 点「**导出批注文档**」
4. 点右上角「**打印 / 存为 PDF**」
5. 在弹出的打印窗口里，把「目标 / 打印机」选成「**另存为 PDF**」
6. **想保留颜色，记得勾选「背景图形 / Background graphics」**（不勾颜色会变灰）

导出的是**每篇一页**的批注单，可以直接打印。

## 关于 DeepSeek API Key

这一段比较重要，请看完。

### 去哪里申请

**https://platform.deepseek.com/api_keys**

（DeepSeek 开放平台。需要先注册账号。新用户通常会有**免费额度**；额度用完后再**充值**一点即可，几块钱能用很久。）

### 它是什么

**DeepSeek** 是一家国产 AI 公司。API Key 是**调用凭证**，相当于一把钥匙 ——
这个小程序本身不会批改，是把作文交给 DeepSeek 的模型来批的，**必须用这把钥匙才能调用**。

### 要花钱吗

**按用量计费**，从你账户余额里扣。注册后通常有免费额度；本工具做了**调用优化**（压缩图片等），费用很低，**批一篇大约几分钱**，不会太高。

> 小提示：**北京时间工作日 18:00 之后、以及周末全天，价格是高峰时段的一半**。
> 晚上和周末批改更划算。

### 一定要保管好

这个 Key 相当于你的**账号密码**：

- ❌ **不要发给别人**，不要发到班级群、工作群
- ❌ **不要截图分享**
- ❌ 不要写在网上任何地方
- ✅ 本应用只把它存在**你自己浏览器的本地存储**里，不会传到任何服务器

### 万一泄露了

立刻去 **https://platform.deepseek.com/api_keys** 把这个 Key **删掉**，
然后**重新创建一个**。旧的立刻就失效了。

## 常见问题

| 提示 | 怎么办 |
| --- | --- |
| 「未配置 API Key」 | 回到**第二步**填 Key |
| 「API Key 无效」 | 检查是否**复制完整**（一般以 `sk-` 开头），有没有多复制空格 |
| 「账户余额不足」 | 去 DeepSeek 平台**充值** |
| 「网络连接中断」 | 检查网络即可，系统会**自动重试 2 次**，一般会自己好 |
| 识别出来的字有错 | 手写体偶尔会认错。点「**对照原图**」可以放大看原照片，**左右滑动**翻页 |
| 批改结果没了 | 记录只存在**这台设备**上。换设备、清理浏览器数据都会丢失 |

## 界面上的颜色含义

| 颜色 | 意思 |
| --- | --- |
| **玫红角标**（右上角数字） | 有 N 篇刚批好、你还没看过的 |
| **直线** —— 红 / 橙 / 紫 | 要改的地方（错别字 / 病句 / 标点） |
| **波浪线** —— 金色 | 写得好的句子 |
| **绿色** | 操作成功（复制成功、已保存、批改完成） |
| **分数颜色** | 绿 = 90 分以上，琥珀 = 80～89，红 = 80 分以下 |
