# 作文批改助手

拍照上传小学生手写作文 → 自动识别 → 给出**可以直接抄到作文本上的批注**和一段总评。

**线上地址：https://gzw.rlearner.com** —— 手机打开就能用，建议加到主屏幕。

---

## 怎么用（四步）

1. **打开** https://gzw.rlearner.com
2. **填一次 Key** —— 点右上角齿轮 → 粘贴 DeepSeek API Key → 点「保存」（会先验证，成功才会写入）
3. **拍作文** —— 「拍照上传」或「从相册选择」；多页可长按拖动排序 → 点「提交批改」
4. **照抄** —— 批注按段落列好，一段一段抄到作文本上

> 💡 **提交完不用等。** 可以立刻接着拍下一篇，批改在后台跑，批好会在顶部提示。
> 第一次大约要等 30～90 秒。

## 输出长什么样

原文一字不改，出问题的地方后面用 `〔→ 改正〕` 标出正确写法：

> 比赛在操场举行。一条又粗又粗`〔→ 又粗又长〕`的麻绳安静地躺在地上，
> 脚底如同有胶水一样黏在地面上`〔生动比喻〕`……

- **直线**（红 / 橙 / 紫）= 要改的地方：错别字 / 病句 / 标点
- **波浪线**（金色）= 写得好的句子
- 每段下方列出该段**全部**批注，带编号，默认展开，不用点
- 最后是 80–100 字总评

支持导出打印版批注单（批改记录 → 选择 → 导出批注文档 → 另存为 PDF）。
